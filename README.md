Program Volume Tabung (dengan Fungsi)
Perangkat program:

public static double hitungVolume(double r, double t)
→ Membuat fungsi khusus untuk menghitung volume tabung.

Math.PI * r * r * t
→ Rumus menghitung volume tabung.

return
→ Mengembalikan nilai hasil perhitungan ke fungsi utama.

double volume = hitungVolume(r, t);
→ Memanggil fungsi hitungVolume() dan menyimpan hasilnya.

System.out.println()
→ Menampilkan hasil volume tabung.

Cara kerjanya:

Program meminta pengguna memasukkan jari-jari dan tinggi tabung. Nilai tersebut dikirim ke fungsi hitungVolume(), lalu dihitung dengan rumus πr²t. Nilai hasilnya dikembalikan ke fungsi utama dan ditampilkan di layar. Program ini melatih konsep fungsi (method) dan penggunaan parameter serta return value.
